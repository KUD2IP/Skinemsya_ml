# Гайд: дообучение модели в Google Colab с нуля

Инструкция для первого знакомства с Colab. Цель — дообучить OCR-модель под русские чеки на бесплатном GPU и получить два файла: `receipt_rec.onnx` и `receipt_rec_keys.txt`.

## Что такое Colab

[Google Colab](https://colab.research.google.com) — бесплатный сервис Google, который даёт виртуальную машину с GPU (обычно NVIDIA T4) и интерфейс Jupyter-ноутбука в браузере. Ничего устанавливать на свой компьютер не нужно. Ограничения бесплатного тарифа: сессия живёт до ~12 часов и сбрасывается при бездействии; все файлы внутри сессии удаляются после её завершения — поэтому результат надо скачивать сразу.

## Шаг 0. Подготовка датасета (локально)

В корне репозитория `Skinemsya_ml`:

```bash
source .venv/bin/activate  # или .venv/bin/python вместо python ниже
python -m training.synthgen --count 3000 --out data/synth
cd data/synth && zip -r ../synth.zip lines rec_gt.txt && cd ../..
```

Получится файл `data/synth.zip` (~150–300 МБ). Это синтетические строки чеков с правильными ответами.

## Шаг 1. Открываем ноутбук в Colab

1. Зайдите на [colab.research.google.com](https://colab.research.google.com) (нужен любой Google-аккаунт).
2. В появившемся окне выберите вкладку **«Загрузить»** (Upload).
3. Загрузите файл `training/colab/finetune_ppocrv5_rec.ipynb` из этого репозитория.

## Шаг 2. Включаем GPU

1. Меню **«Среда выполнения»** (Runtime) → **«Сменить среду выполнения»** (Change runtime type).
2. В поле «Аппаратный ускоритель» выберите **T4 GPU**.
3. Нажмите «Сохранить».

Без этого шага обучение будет идти на CPU в десятки раз дольше.

## Шаг 3. Выполняем ячейки по порядку

Ячейка — это блок кода. Чтобы выполнить её, кликните по ней и нажмите **Shift+Enter** (или кнопку ▶ слева от ячейки). Дождитесь, пока слева от ячейки исчезнет крутящийся индикатор, и только потом запускайте следующую.

Что делает каждая ячейка:

| Ячейка | Что происходит | Сколько ждать |
| --- | --- | --- |
| 1 | Проверка, что GPU выдан (`nvidia-smi`) | секунды |
| 2 | Установка PaddlePaddle и PaddleOCR | ~5 мин |
| 3 | Загрузка `synth.zip` — появится кнопка выбора файла | зависит от интернета |
| 4 | Разбиение на train/val, поиск словаря символов | секунды |
| 5 | **Обучение** | 30–60 мин |
| 6 | Экспорт модели и конвертация в ONNX | ~2 мин |
| 7 | Скачивание `receipt_rec.onnx` и `receipt_rec_keys.txt` | секунды |

Примечания:

- В ячейке 3 при первом запуске Colab может спросить разрешение на доступ к файлам — разрешите.
- Во время обучения (ячейка 5) в логах видна метрика `acc` — доля строк валидации, распознанных полностью верно. Хороший результат — `acc > 0.9`. Значение `best_accuracy` сохраняется автоматически.
- Если сессия оборвалась — не страшно: запустите все ячейки заново («Среда выполнения» → «Запустить все»), данные придётся загрузить снова.
- Если хотите обучить дольше/лучше — увеличьте `Global.epoch_num` в ячейке 5 (например, до 20) и/или сгенерируйте больше данных (`--count 10000`).

## Шаг 4. Подключаем модель к сервису

1. Скачанные файлы положите в `Skinemsya_ml/data/models/`:
   - `receipt_rec.onnx`
   - `receipt_rec_keys.txt`
2. Сравните качество с базовой моделью на eval-наборе:

```bash
python scripts/evaluate.py --dataset data/synth_eval
python scripts/evaluate.py --dataset data/synth_eval \
    --rec-model data/models/receipt_rec.onnx --rec-keys data/models/receipt_rec_keys.txt
```

3. Если метрики лучше — запускайте сервис с новой моделью:

```bash
ML_REC_MODEL_PATH=data/models/receipt_rec.onnx \
ML_REC_KEYS_PATH=data/models/receipt_rec_keys.txt \
uvicorn app.main:app --port 8000
```

В Docker — раскомментируйте volume `./data/models:/custom:ro` и переменные `ML_REC_MODEL_PATH`/`ML_REC_KEYS_PATH` в `docker-compose.yml` и пересоздайте контейнер.

## Частые проблемы

- **«Не удалось выделить GPU»** — бесплатные GPU иногда заканчиваются. Подождите час-два или попробуйте в другое время суток.
- **Ячейка 2 падает на установке paddlepaddle-gpu** — версия CUDA в Colab могла обновиться. Откройте [paddlepaddle.org.cn/en/install/quick](https://www.paddlepaddle.org.cn/en/install/quick), выберите Linux + pip + GPU и подставьте предложенную команду установки.
- **Обучение упало с out of memory** — уменьшите `Train.loader.batch_size_per_card` со 128 до 64 в ячейке 5.
- **`acc` близка к нулю после первой эпохи** — это нормально в самом начале; если после 2–3 эпох не растёт, проверьте, что в ячейке 4 не было символов вне словаря.
